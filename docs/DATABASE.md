# Database & Storage Specification
## Project: Colombian Language Academy Intelligent Assistant (RAG Pipeline)

---

## 1. Storage Architecture Overview

The system employs a decoupled two-tier local storage design:
1. **Vector Storage (ChromaDB):** Persistent document chunk indices and semantic cache query embeddings.
2. **Relational Database (SQLite via Async SQLAlchemy):** Relational operational logs, student escalation sessions, live advisor messages, and telemetry metrics.

---

## 2. Relational Schema (SQLite / SQLAlchemy)

### Entity: `telemetry_logs`
Stores detailed execution telemetry for each processed inquiry.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | `INTEGER` | Primary Key, Auto Increment | Unique record identifier. |
| `session_id` | `VARCHAR(64)` | Indexed, Not Null | Session/conversation identifier. |
| `timestamp` | `DATETIME` | Not Null, Default UTC | Interaction timestamp. |
| `channel` | `VARCHAR(32)` | Not Null | Channel origin (`web`, `telegram`, `webhook`). |
| `user_query` | `TEXT` | Not Null | Original raw prompt sent by student. |
| `bot_response` | `TEXT` | Not Null | Final text payload returned to student. |
| `status` | `VARCHAR(32)` | Not Null, Indexed | Enum: `RESOLVED_BY_CACHE`, `RESOLVED_BY_RAG`, `ESCALATED_TO_HUMAN`. |
| `escalation_reason` | `VARCHAR(64)` | Nullable | Reason tag (e.g., `LOW_SIMILARITY`, `UNGROUNDED_CONTEXT`, `OUT_OF_SCOPE`). |
| `latency_ms` | `FLOAT` | Not Null | Total round-trip execution latency in milliseconds. |
| `prompt_tokens` | `INTEGER` | Not Null, Default 0 | Input tokens consumed in LLM inference. |
| `completion_tokens` | `INTEGER` | Not Null, Default 0 | Output tokens generated by LLM. |
| `cost_usd` | `FLOAT` | Not Null, Default 0.0 | Estimated total cost based on token pricing model. |

## 3. Vector Database Collections (ChromaDB)

Persisted under `./backend/data/chroma_db`.

### Collection 1: `academy_docs`
* **Purpose:** Stores chunked official language academy business knowledge.
* **Embedding Model:** Configured dynamically via `LLM_PROVIDER`:
  * OpenAI: `text-embedding-3-small` (1536 dimensions)
  * Gemini: `models/text-embedding-004` (768 dimensions)
* **Ingested Documents:**
  * `cursos_y_modalidades.md`
  * `precios_y_metodos_de_pago.md`
  * `inscripciones_y_certificaciones.md`
* **Chunking Strategy:** `RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=100)`.
* **Metadata Schema:**
  ```json
  {
    "source_file": "precios_y_metodos_de_pago.md",
    "section": "Tarifas Oficiales de Matrícula y Programas",
    "chunk_id": "precios_y_metodos_de_pago_chunk_04"
  }
  ```

### Collection 2: `semantic_cache`
* **Purpose:** High-efficiency cache for frequent and paraphrased questions.
* **Similarity Threshold:** Cosine distance $\le 0.08$ ($\ge 92\%$ similarity).
* **Metadata Schema:**
  ```json
  {
    "query": "How much does the intensive English course cost?",
    "response": "The intensive English module (40 hours) costs $650,000 COP...",
    "created_at": "2026-08-31T07:00:00Z"
  }
  ```
